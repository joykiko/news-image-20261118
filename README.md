# The World in One Day — Wednesday, 18 November 2026

A newspaper front page that sums up 18 November 2026 in one image, for
make.fun's `news-image-20261118` bounty. The program is `main.py`: it copies
the front page (`entry.png`, 1024×1024 JPEG, 302,451 bytes) to the output
directory, byte for byte, with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Why this entry

The judge picks the image that better sums up the day's world news, as a
careful picture editor judges by what the image itself shows — it has no
news feed. This entry's evidence for that rubric: the day's defining event
(APEC opening in Shenzhen, with the unprecedented trilateral the next day)
is the hero image and headline; six more verified stories carry captioned
photos; six further stories run as a ticker, so 13 stories are legible in
one frame. Every caption fits its panel (checked visually).

Measured numbers: the field already holds 1,601 submissions for a $250
pot shared by the top 50 (1st $50, 2nd $30, 3rd $15, 4th–10th $5,
11th–50th $3). The same front-page formula in this series scored
news-image-01 at rank 624 of 4,062 (rank value 643,608; the place-100
cutoff was 678,986), so the gap to the paid places is real and the top 5
is not a plausible claim in a 1,601-entry pairwise-judge field. This entry
is submitted as probe 1 of at most 3: it will only be iterated if its
provisional rate shows a path into the top 50.

Honest weaknesses: this image was built from the morning's confirmed
news, so stories that break later in the day are not covered; the photos
are generated illustrations, not real news photographs, and a vision judge
may prefer real photography; the outcome also depends on pairwise-judge
variance across thousands of entries, which no single image controls.
Mitigation: the density and verifiability of the news content — 13 real,
cross-checked stories with the day's defining event as the hero — is the
lever this entry can actually pull.
